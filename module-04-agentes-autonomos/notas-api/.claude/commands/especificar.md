description: Cria a especificação (o QUE e por quê) de uma feature, sem código
---

Escreva uma ESPECIFICAÇÃO para a feature descrita a seguir:

- Leia specs/constitution.md e respeite todos os principios.
- NÃO escreva código nem decisões de implementação
- Crie specs/<NNN>-<slug>spec.md (próximo numero livre) com:

1. Contexto/problema
2. User Stories ("Com <papel>, quero <Objetivo>, para <beneficio>")
3. Requisitos funcionais numerados (RF-1...)
4. Critérios de aceite em EARS ("Quando <evento>, o sistema deve <resposta>")
5. Fora de escopo
6. Questões em aberto

- Se algo estiver ambiguo, PERGUNTE antes de finalizar
